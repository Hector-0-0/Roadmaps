# Checkpoint 02 - Apps CLI

## Objetivo del checkpoint
Crear aplicaciones CLI (Command Line Interface, interfaz de línea de comandos) con Node.js.

## Conocimientos que consolida
- [01-nodejs](../01-nodejs/README.md)

## 3 ideas de proyecto de dificultad creciente

### 1. Proyecto 1: Lista de tareas CLI (Dificultad: básica)
**Descripción:** Agregar, listar, eliminar tareas desde CLI.

**Requisitos funcionales:**
- Comandos: add, list, remove.
- Guardar en archivo JSON.
- Mostrar mensajes claros.

**Habilidades que practica:**
- process.argv, fs, JSON.

**Criterios de aceptación:**
- Funciona por comandos.
- Persiste datos en archivo.
- Maneja errores básicos.

**Mejoras opcionales:**
- Marcar completado.
- Colores en terminal.

### 2. Proyecto 2: Notas CLI (Dificultad: intermedia)
**Descripción:** Crear, leer, buscar notas.

**Requisitos funcionales:**
- add, read, list, search.
- Almacenamiento JSON.
- Búsqueda por título.

**Habilidades que practica:**
- Módulos, organización, validación.

**Criterios de aceptación:**
- CRUD básico funcional.
- Búsqueda funciona.
- Datos persisten.

**Mejoras opcionales:**
- Editar nota.
- Fechas.

### 3. Proyecto 3: Generador de archivos (Dificultad: intermedia)
**Descripción:** Generar archivos con plantillas desde CLI.

**Requisitos funcionales:**
- Comando para generar HTML/JS básico.
- Templates (plantillas).
- Nombre personalizado.
- Validación.

**Habilidades que practica:**
- fs, path, plantillas.

**Criterios de aceptación:**
- Genera archivos correctos.
- Usa rutas correctas.
- Mensajes claros.

**Mejoras opcionales:**
- Múltiples plantillas.
- Ayuda (--help).
