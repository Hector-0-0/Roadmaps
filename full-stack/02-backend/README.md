# 02-backend

## Objetivo de la etapa
Aprender a construir el lado del servidor (servidor) de aplicaciones web. Se aborda Node.js (entorno de ejecución de JavaScript), creación de CLI (Command Line Interface, interfaz de línea de comandos), APIs RESTful (Representational State Transfer, transferencia de estado representacional), bases de datos relacionales con PostgreSQL, caché (almacenamiento temporal) con Redis, autenticación con JSON Web Token (JWT, token web JSON) y desarrollo de una aplicación completa.
