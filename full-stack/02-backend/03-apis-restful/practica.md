# Práctica - 03-apis-restful

## Nivel básico
1. **API básica** (criterio: terminado)
   Enunciado: Crear API con GET /users que retorne array.
   Pista: Usa Express o http nativo.

2. **Métodos HTTP** (criterio: terminado)
   Enunciado: Implementar GET, POST básicos.
   Pista: Usa express.json().

## Nivel intermedio
3. **CRUD completo** (criterio: terminado)
   Enunciado: CRUD para recurso users sin BD.
   Pista: Usa array en memoria.

4. **Códigos de estado** (criterio: terminado)
   Enunciado: Usar códigos correctos (200, 201, 404).
   Pista: res.status().

## Nivel desafío
5. **Validación básica** (criterio: terminado)
   Enunciado: Validar datos en POST y retornar 400 si faltan.
   Pista: Sin librerías complejas.
