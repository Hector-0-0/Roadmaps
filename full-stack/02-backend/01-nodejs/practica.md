# Práctica - 01-nodejs

## Nivel básico
1. **Servidor HTTP** (criterio: terminado)
   Enunciado: Crea servidor que responda "Hola mundo" en puerto 3000.
   Pista: Usa módulo http.

2. **Rutas básicas** (criterio: terminado)
   Enunciado: Maneja rutas /, /about, 404.
   Pista: Usa req.url.

## Nivel intermedio
3. **Módulos propios** (criterio: terminado)
   Enunciado: Separa lógica en módulos (funciones) e impórtalos.
   Pista: module.exports/require.

4. **Leer archivos** (criterio: terminado)
   Enunciado: Lee archivo HTML y envíalo como respuesta.
   Pista: Usa fs.readFile.

## Nivel desafío
5. **CLI simple** (criterio: terminado)
   Enunciado: CLI que tome argumentos y realice acción simple.
