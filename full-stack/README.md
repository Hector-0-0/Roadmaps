# Full Stack

## Objetivo
Aprender desarrollo full-stack de forma integral, desde la construcción de interfaces (frontend) hasta la lógica de negocio, APIs (Application Programming Interface, interfaz de programación de aplicaciones), bases de datos, despliegue (deployment) y automatización. Se busca adquirir bases sólidas y aplicarlas construyendo proyectos en cada checkpoint.

## Público objetivo
Principiantes absolutos que quieren entrar al desarrollo full-stack.
