# Práctica - 04-javascript

## Nivel básico
1. **Variables y tipos** (criterio: terminado)
   Enunciado: Declara variables con `let`, `const` y muestra sus tipos con `typeof`.
   Pista: Usa `console.log`.

2. **Condicionales** (criterio: terminado)
   Enunciado: Crea un programa que verifique si un número es par o impar.
   Pista: Usa operador `%`.

## Nivel intermedio
3. **Funciones y arrays** (criterio: terminado)
   Enunciado: Crea una función que filtre números mayores a 10 en un array.
   Pista: Usa `filter()` o bucle `for`.

4. **Manipulación DOM** (criterio: terminado)
   Enunciado: Cambia el texto de un elemento al hacer clic en un botón.
   Pista: Usa `querySelector`, `addEventListener`, `textContent`.

## Nivel desafío
5. **Lista de tareas (To-Do)** (criterio: terminado)
   Enunciado: Crea una lista de tareas con agregar y eliminar elementos.
   Pista: Usa `createElement`, `appendChild`, `remove()`. Sin persistencia necesaria.
