# 01-frontend

## Objetivo de la etapa
Construir las bases del desarrollo web (World Wide Web, red mundial), aprender a estructurar contenido con HTML (HyperText Markup Language, lenguaje de marcado de hipertexto), dar estilo con CSS (Cascading Style Sheets, hojas de estilo en cascada), añadir interactividad con JavaScript (JavaScript, lenguaje de programación), gestionar dependencias con npm (Node Package Manager, gestor de paquetes de Node), controlar versiones con Git y GitHub, y sentar las bases para frameworks (marcos de trabajo). Se incluyen temas opcionales (React, Tailwind CSS) para revisar después de Backend.
