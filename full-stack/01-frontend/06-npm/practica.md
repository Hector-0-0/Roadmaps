# Práctica - 06-npm

## Nivel básico
1. **Inicializar proyecto** (criterio: terminado)
   Enunciado: Inicializa un proyecto con npm y crea package.json.
   Pista: Usa `npm init -y`.

2. **Instalar paquete** (criterio: terminado)
   Enunciado: Instala un paquete pequeño (ej. dayjs) y úsalo.
   Pista: Requiere Node.js instalado.

## Nivel intermedio
3. **Scripts** (criterio: terminado)
   Enunciado: Crea un script "start" en package.json para ejecutar tu archivo.
   Pista: Usa `npm run start`.

4. **.gitignore** (criterio: terminado)
   Enunciado: Crea .gitignore y agrega node_modules.
   Pista: Fundamental para Git.

## Nivel desafío
5. **Proyecto con dependencias** (criterio: terminado)
   Enunciado: Usa al menos dos paquetes (uno producción, uno desarrollo o ambos) y documenta su uso.
   Pista: Piensa en utilidad real.
