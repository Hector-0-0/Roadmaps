# Práctica - 02-css

## Nivel básico
1. **Selectores** (criterio: terminado)
   Enunciado: Aplica estilos con selector de elemento, clase e ID.
   Pista: Crea 3 elementos distintos y estílalos cada uno.

2. **Box Model** (criterio: terminado)
   Enunciado: Crea una caja con padding, border y margin. Observa el efecto.
   Pista: Usa `box-sizing: border-box` para controlar mejor el tamaño.

## Nivel intermedio
3. **Flexbox** (criterio: terminado)
   Enunciado: Crea un contenedor con 3 elementos usando Flexbox para alinearlos horizontalmente y centrarlos.
   Pista: Usa `display: flex`, `justify-content`, `align-items`.

4. **Responsive básico** (criterio: terminado)
   Enunciado: Usa media queries (consultas de medios) para cambiar estilos en pantallas menores a 600px.
   Pista: Cambia color o layout con `@media (max-width: 600px)`.

## Nivel desafío
5. **Tarjeta con Flexbox/Grid** (criterio: terminado)
   Enunciado: Diseña una tarjeta (card) con imagen, título, texto y botón, usando Flexbox o Grid.
   Pista: Enfócate en espaciado y legibilidad.
