# Checkpoint 05 - Interactividad

## Objetivo del checkpoint
Consolidar JavaScript con DOM y eventos creando páginas interactivas.

- [01-html](../01-html/README.md)
- [02-css](../02-css/README.md)

## 3 ideas de proyecto de dificultad creciente

### 1. Proyecto 1: Calculadora básica (Dificultad: básica)
**Descripción:** Calculadora con operaciones básicas.

**Requisitos funcionales:**
- Botones numéricos y operadores.
- Pantalla para mostrar resultado.
- Operaciones: suma, resta, multiplicación, división.
- Botón limpiar.

**Habilidades que practica:**
- Eventos, manipulación DOM, lógica condicional.

**Criterios de aceptación:**
- Funciona sin errores básicos.
- Actualiza pantalla correctamente.
- Limpia correctamente.

**Mejoras opcionales:**
- Decimales.
- Validación de división por cero.

### 2. Proyecto 2: Lista de tareas interactiva (Dificultad: intermedia)
**Descripción:** To-Do con agregar, marcar completado, eliminar.

**Requisitos funcionales:**
- Input para nueva tarea.
- Botón agregar.
- Lista con tareas.
- Marcar como completado.
- Eliminar tarea.

**Habilidades que practica:**
- Arrays, eventos, creación dinámica de elementos.

**Criterios de aceptación:**
- Agregar y eliminar funcionan.
- Estado completado visual.
- Sin recarga de página.

**Mejoras opcionales:**
- Guardar en localStorage (almacenamiento local).
- Filtro por completadas/pendientes.

### 3. Proyecto 3: Formulario con validación (Dificultad: intermedia)
**Descripción:** Formulario con validación en tiempo real o al enviar.

**Requisitos funcionales:**
- Campos: nombre, correo, contraseña.
- Validación de campos obligatorios.
- Validación de formato de correo.
- Mensajes de error.
- Envío solo si válido.

**Habilidades que practica:**
- Eventos submit, expresiones regulares básicas, DOM.

**Criterios de aceptación:**
- Muestra errores claros.
- No envía si hay errores.
- Mensajes descriptivos.

**Mejoras opcionales:**
- Mostrar fortaleza de contraseña.
- Validación en tiempo real.
