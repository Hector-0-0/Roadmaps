# Práctica - 01-html

## Nivel básico
1. **Estructura mínima** (criterio: terminado)
   Enunciado: Crea un archivo `index.html` con la estructura mínima válida en español.
   Pista: Usa `<!DOCTYPE html>`, `html lang="es"`, `head`, `body`.

2. **Encabezados y párrafos** (criterio: terminado)
   Enunciado: Agrega un título con `<h1>`, un subtítulo con `<h2>` y dos párrafos con `<p>`.
   Pista: Usa contenido real sobre un tema que te guste.

## Nivel intermedio
3. **Enlaces e imágenes** (criterio: terminado)
   Enunciado: Agrega un enlace a una página externa y una imagen con texto alternativo.
   Pista: Usa `target="_blank"` solo si lo consideras necesario y entiende sus implicaciones.

4. **Listas y tablas** (criterio: terminado)
   Enunciado: Crea una lista ordenada y una no ordenada. Luego crea una tabla simple con al menos 3 filas.
   Pista: Piensa en datos reales (ej. tareas o productos).

## Nivel desafío
5. **Página semántica** (criterio: terminado)
   Enunciado: Estructura una página con `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`.
   Pista: Usa etiquetas semánticas para dar significado a cada parte.
