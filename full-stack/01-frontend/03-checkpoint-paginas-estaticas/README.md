# Checkpoint 03 - Páginas estáticas

## Objetivo del checkpoint
Consolidar HTML y CSS creando páginas web estáticas (sin interactividad con JavaScript) completas y bien estructuradas.

## Conocimientos que consolida
- [01-html](../01-html/README.md): estructura, elementos, semántica.
- [02-css](../02-css/README.md): estilos, Box Model, Flexbox, responsive básico.

## 3 ideas de proyecto de dificultad creciente

### 1. Proyecto 1: Sitio personal estático (Dificultad: básica)
**Descripción:** Página personal con información, habilidades y contacto.

**Requisitos funcionales:**
- Header con nombre y navegación.
- Sección "Sobre mí".
- Sección "Habilidades" con lista.
- Sección "Contacto" con información.
- Footer.

**Habilidades que practica:**
- HTML semántico, CSS básico, organización de archivos.

**Criterios de aceptación:**
- Estructura semántica correcta.
- Estilos aplicados con CSS externo.
- Navegación funcional entre secciones.
- Responsive básico.

**Mejoras opcionales:**
- Agregar foto.
- Mejorar tipografía con Google Fonts (verificar enlace).

### 2. Proyecto 2: Página de producto (Dificultad: intermedia)
**Descripción:** Landing page (página de aterrizaje) de un producto con descripción, características y llamado a acción.

**Requisitos funcionales:**
- Imagen del producto.
- Descripción detallada.
- Lista de características.
- Botón de acción.
- Sección de testimonios.

**Habilidades que practica:**
- Layout con Flexbox, espaciado, jerarquía visual.

**Criterios de aceptación:**
- Diseño claro y legible.
- Uso correcto de Box Model.
- Botón visible y centrado.
- Responsive en móvil.

**Mejoras opcionales:**
- Galería de imágenes.
- Animaciones con CSS.

### 3. Proyecto 3: Blog estático (Dificultad: intermedia-avanzada)
**Descripción:** Blog con página principal y al menos 2 entradas de blog.

**Requisitos funcionales:**
- Página principal con lista de posts.
- Páginas individuales para cada post.
- Navegación entre páginas.
- Sidebar (barra lateral) con categorías o información.

**Habilidades que practica:**
- Múltiples páginas HTML, CSS compartido, organización de proyecto.

**Criterios de aceptación:**
- Navegación funcional.
- CSS externo compartido.
- Estructura semántica en posts.
- Responsive básico.

**Mejoras opcionales:**
- Sistema de etiquetas.
- Diseño tipo revista.
