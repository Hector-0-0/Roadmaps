# Práctica - 08-git-y-github

## Nivel básico
1. **Repo local** (criterio: terminado)
   Enunciado: Crea un repo local, agrega archivos y haz commits.
   Pista: Usa init, add, commit.

2. **.gitignore** (criterio: terminado)
   Enunciado: Configura .gitignore para archivos que no deben trackearse.
   Pista: Ej. node_modules, .env.

## Nivel intermedio
3. **Ramas** (criterio: terminado)
   Enunciado: Crea una rama, haz cambios, vuelve a main.
   Pista: Usa branch, checkout/switch.

4. **Remoto** (criterio: terminado)
   Enunciado: Conecta con GitHub y sube cambios.
   Pista: Usa remote, push.

## Nivel desafío
5. **Flujo colaborativo simulado** (criterio: terminado)
   Enunciado: Simula PR: crea rama, cambios, merge local. Documenta pasos.
   Pista: Entiende flujo antes de colaborar.
