## 3 ideas de proyecto de dificultad creciente

### 1. Proyecto 1: App de clima (Dificultad: intermedia)
**Descripción:** Consultar clima usando API pública (aplicación de programación).

**Requisitos funcionales:**
- Input para ciudad.
- Mostrar temperatura, descripción.
- Manejo de errores.
- Estilos básicos.

**Habilidades que practica:**
- Fetch API, JSON, async/await básico, DOM.

**Criterios de aceptación:**
- Obtiene datos de API.
- Muestra información clara.
- Maneja ciudad no encontrada.

**Mejoras opcionales:**
- Iconos.
- Geolocalización.

### 2. Proyecto 2: Buscador de películas (Dificultad: intermedia)
**Descripción:** Buscar películas con API.

**Requisitos funcionales:**
- Campo de búsqueda.
- Lista de resultados.
- Detalles al seleccionar.
- Estados de carga.

**Habilidades que practica:**
- Fetch, eventos, renderizado dinámico.

**Criterios de aceptación:**
- Búsqueda funcional.
- Resultados legibles.
- Sin errores en consola.

**Mejoras opcionales:**
- Paginación.
- Favoritos con localStorage.

### 3. Proyecto 3: Dashboard con datos (Dificultad: intermedia-avanzada)
**Descripción:** Dashboard con múltiples secciones y datos.

**Requisitos funcionales:**
- Múltiples secciones.
- Gráficas simples con datos estáticos o API.
- Filtros.
- Diseño responsive.

**Habilidades que practica:**
- Integración completa, organización, responsive.

**Criterios de aceptación:**
- Funcionalidad completa.
- Código organizado.
- Responsive.

**Mejoras opcionales:**
- Usar módulo JS.
- Mejorar accesibilidad.
