# 10-terraform

## 1. Qué es y para qué sirve
Terraform es IaC (Infrastructure as Code, infraestructura como código). Permite aprovisionar infraestructura con archivos declarativos.

## 2. Conceptos clave
- Providers (proveedores)
- Resources (recursos)
- State (estado)
- Plan/Apply/Destroy
- HCL (HashiCorp Configuration Language)

```hcl
provider "aws" {
  region = "us-east-1"
}
```
