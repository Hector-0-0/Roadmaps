# Práctica - 01-linux-basico

## Nivel básico
1. **Navegación** (criterio: terminado)
   Enunciado: Navegar por directorios, crear/borrar.
   Pista: pwd, ls, cd, mkdir, rm.

2. **Archivos** (criterio: terminado)
   Enunciado: Crear, leer, copiar, mover archivos.
   Pista: touch, cat, cp, mv.

## Nivel intermedio
3. **Permisos** (criterio: terminado)
   Enunciado: Modificar permisos con chmod.
   Pista: r,w,x.

4. **Procesos** (criterio: terminado)
   Enunciado: Ver procesos y matar si necesario.
   Pista: ps, kill.

## Nivel desafío
5. **SSH** (criterio: terminado)
   Enunciado: Conectarse por SSH a servidor (simulado o real).
   Pista: ssh usuario@ip.
