# 03-devops

## Objetivo de la etapa
Aprender conceptos básicos de sistemas operativos (Linux), servicios básicos en AWS (Amazon Web Services), despliegue, monitoreo, integración y entrega continua (CI/CD, Continuous Integration/Continuous Delivery, integración continua/entrega continua), automatización con Ansible y aprovisionamiento de infraestructura con Terraform (Terraform, herramienta de infraestructura como código).
