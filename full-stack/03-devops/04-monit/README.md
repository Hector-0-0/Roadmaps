# 04-monit

## 1. Qué es y para qué sirve
Monitoreo (monitoring) es observar salud, rendimiento y disponibilidad de sistemas/aplicaciones.

## 2. Conceptos clave
- Métricas: CPU, memoria, disco, red
- Logs (registros)
- Alertas
- Uptime
- Monitoreo básico con herramientas

## 3. Práctica orientativa
- Revisar logs con journalctl
- Monitorear con top/htop
- Configurar chequeo básico
