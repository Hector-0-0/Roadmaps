# 02-servicios-basicos-aws

## 1. Qué es y para qué sirve
AWS (Amazon Web Services) es plataforma de nube (cloud computing). Se verán servicios básicos: EC2, VPC, Route53, SES, S3.

## 2. Sub-temas

### EC2 (Elastic Compute Cloud)
Máquinas virtuales en nube. IaaS (Infrastructure as a Service).
Conceptos: AMI, instance type, security groups, key pairs.

### VPC (Virtual Private Cloud)
Red privada virtual. Subnets, route tables, internet gateway, NAT (conceptos).

### Route 53
DNS (Domain Name System) gestionado. Dominios, registros A/CNAME.

### SES (Simple Email Service)
Envío de emails transaccionales.

### S3 (Simple Storage Service)
Almacenamiento de objetos. Buckets, objetos, permisos, static website hosting.

## 3. Notas
Se recomienda práctica en Free Tier (capa gratuita). Siempre eliminar recursos para evitar costos.
