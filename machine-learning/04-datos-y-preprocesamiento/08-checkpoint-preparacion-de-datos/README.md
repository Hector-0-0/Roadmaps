# Checkpoint

## Objetivo

Consolidar los conocimientos de la etapa mediante proyectos integradores aplicados a Machine Learning con datasets públicos.

## Conocimientos que consolida

- Conceptos teóricos de la etapa
- Implementación práctica con Python y librerías
- Evaluación correcta con métricas apropiadas
- Código reproducible y documentado

## Proyectos

### Proyecto 1: Exploración y análisis (Dificultad: Básico)

**Descripción:** Realizar análisis exploratorio completo de un dataset clásico aplicando técnicas de la etapa.

**Requisitos funcionales:**
- Cargar dataset con código
- Aplicar técnicas aprendidas
- Visualizar resultados
- Documentar hallazgos

**Habilidades que practica:** Análisis, visualización, Python

**Criterios de aceptación:**
- Código ejecutable sin errores
- Análisis con hallazgos numéricos
- Visualizaciones con etiquetas correctas
- Conclusiones fundamentadas

**Mejoras opcionales:**
- Añadir estadísticas adicionales
- Comparar con otro dataset

### Proyecto 2: Implementación y evaluación (Dificultad: Intermedio)

**Descripción:** Implementar solución completa con validación y métricas apropiadas.

**Requisitos funcionales:**
- Preparación de datos correcta
- Implementación de técnicas
- División train/test o validación cruzada
- Evaluación con métricas correctas

**Habilidades que practica:** Modelado, validación, métricas

**Criterios de aceptación:**
- Sin fuga de datos
- Métricas calculadas correctamente
- Validación aplicada
- Resultados interpretables

**Mejoras opcionales:**
- Comparar múltiples enfoques
- Ajustar hiperparámetros

### Proyecto 3: Proyecto integrador completo (Dificultad: Desafío)

**Descripción:** Desarrollar proyecto end to end desde datos hasta evaluación, documentado completamente.

**Requisitos funcionales:**
- Problema claramente definido
- Pipeline completo reproducible
- Evaluación rigurosa
- Documentación clara con resultados
- Código limpio y organizado

**Habilidades que practica:** Integración, pensamiento crítico, documentación

**Criterios de aceptación:**
- Pipeline reproducible
- Métricas numéricas reportadas
- Conclusiones basadas en evidencia
- Código ejecutable
- Documentación completa

**Mejoras opcionales:**
- Añadir mejoras propuestas
- Considerar aspectos éticos
- Sugerir próximos pasos
