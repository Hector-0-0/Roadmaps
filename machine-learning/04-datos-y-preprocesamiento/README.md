# Datos y preprocesamiento

## Objetivo

Aprender a recolectar, limpiar, transformar y preparar datos para modelos de Machine Learning. Se cubren fuentes, formatos, limpieza, reducción dimensional, ingeniería de características, selección y escalado.

## Mapa de temas

- [01-fuentes-y-recoleccion-de-datos](01-fuentes-y-recoleccion-de-datos/README.md): Bases SQL/NoSQL, APIs, apps móviles, IoT.
- [02-formatos-de-datos](02-formatos-de-datos/README.md): JSON, CSV, Excel, Parquet y otros formatos.
- [03-limpieza-de-datos](03-limpieza-de-datos/README.md): Valores faltantes, outliers, duplicados y tipos de datos.
- [04-reduccion-de-dimensionalidad](04-reduccion-de-dimensionalidad/README.md): PCA, técnicas de reducción.
- [05-ingenieria-de-caracteristicas](05-ingenieria-de-caracteristicas/README.md): Creación y transformación de features.
- [06-seleccion-de-caracteristicas](06-seleccion-de-caracteristicas/README.md): Métodos de selección.
- [07-escalado-y-normalizacion](07-escalado-y-normalizacion/README.md): StandardScaler, MinMaxScaler, robust scaling.
- [08-checkpoint-preparacion-de-datos](08-checkpoint-preparacion-de-datos/README.md): Proyecto integrador de preparación.

## Cómo avanzar

Sigue el orden, practica con datasets públicos y verifica con `python3 scripts/verificar.py`.
