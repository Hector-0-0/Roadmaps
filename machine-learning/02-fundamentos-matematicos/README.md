# Fundamentos matemáticos

## Objetivo

Esta etapa proporciona los fundamentos matemáticos necesarios para comprender algoritmos de Machine Learning. Se estudian cálculo, álgebra lineal, estadística, probabilidad y matemática discreta con ejemplos numéricos en Python.

## Mapa de temas

- [01-calculo](01-calculo/README.md): Derivadas y parciales, regla de la cadena, gradiente, jacobiano, hessiano con ejemplo de descenso por gradiente.
- [02-algebra-lineal](02-algebra-lineal/README.md): Escalares, vectores, tensores, matrices, operaciones, determinante, inversa, autovalores, diagonalización, SVD.
- [03-estadistica](03-estadistica/README.md): Estadística descriptiva e inferencial, gráficos, media, varianza, intervalos de confianza.
- [04-probabilidad](04-probabilidad/README.md): Probabilidad básica, variables aleatorias, PDFs, distribuciones, teorema de Bayes.
- [05-matematica-discreta](05-matematica-discreta/README.md): Conjuntos, lógica, combinatoria, conteo y grafos aplicados a ML.
- [06-checkpoint-fundamentos-matematicos](06-checkpoint-fundamentos-matematicos/README.md): Proyectos integradores para consolidar los fundamentos.

## Cómo avanzar

Resuelve cada tema con sus fórmulas, ejemplos ejecutables, prácticas y recursos. Verifica con `python3 scripts/verificar.py` al terminar la etapa.
