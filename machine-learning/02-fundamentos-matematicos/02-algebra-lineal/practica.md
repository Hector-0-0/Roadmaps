# Práctica

## Nivel básico

1. **Conceptos fundamentales**
   Enunciado: Define con tus palabras los conceptos clave del tema y da un ejemplo numérico.
   Pista: Usa definiciones claras y relaciona con ejemplos aplicados a Machine Learning.
   Criterio verificable: Definiciones correctas, ejemplo numérico válido y relación con ML explícita.

2. **Cálculos con NumPy**
   Enunciado: Usa NumPy para calcular media, varianza, desviación estándar y norma de un vector.
   Pista: Usa np.mean, np.var, np.std. Para norma usa np.linalg.norm.
   Criterio verificable: Todos los cálculos correctos con código ejecutable.

3. **Operaciones matriciales**
   Enunciado: Crea dos matrices, realiza producto matricial, transpuesta y determinante.
   Pista: Usa @ o np.dot para producto. Usa .T para transpuesta y np.linalg.det.
   Criterio verificable: Operaciones realizadas correctamente con resultados verificados.

## Nivel intermedio

4. **Aplicación numérica**
   Enunciado: Resuelve un ejercicio numérico relacionado al tema con Python y verifica el resultado.
   Pista: Usa datos sencillos para poder verificar manualmente los cálculos.
   Criterio verificable: Resultado numérico correcto, código ejecutable y verificación explícita.

5. **Visualización básica**
   Enunciado: Genera una visualización con Matplotlib relacionada al concepto estudiado.
   Pista: Usa plt.plot o plt.hist según corresponda al tema.
   Criterio verificable: Gráfica generada con etiquetas correctas y código ejecutable.

6. **Conexión con ML**
   Enunciado: Explica cómo el concepto se usa en algún algoritmo de ML con ejemplo numérico simple.
   Pista: Relaciona con regresión, clasificación o descenso por gradiente.
   Criterio verificable: Explicación correcta con ejemplo numérico verificable.

## Nivel desafío

7. **Ejercicio integrador numérico**
   Enunciado: Resuelve un problema integrador que combine al menos dos conceptos del tema con cálculo numérico verificable.
   Pista: Define valores, calcula paso a paso y verifica con código.
   Criterio verificable: Solución numérica correcta con pasos documentados y verificación con assert o resultado esperado.

8. **Implementación desde cero**
   Enunciado: Implementa una operación matemática básica desde cero con Python puro y compara con NumPy.
   Pista: Usa listas y bucles. Compara resultados numéricos.
   Criterio verificable: Implementación correcta, comparación con NumPy exitosa, diferencia numérica aceptable.
