# Machine Learning clásico

## Objetivo

Estudiar tipos de Machine Learning y algoritmos clásicos supervisados, no supervisados y por refuerzo, con implementación práctica.

## Mapa de temas

- [01-tipos-de-machine-learning](01-tipos-de-machine-learning/README.md): Supervisado, no supervisado, semisupervisado, por refuerzo, autosupervisado.
- [02-aprendizaje-supervisado-regresion](02-aprendizaje-supervisado-regresion/README.md): Regresión lineal y polinómica.
- [03-aprendizaje-supervisado-clasificacion](03-aprendizaje-supervisado-clasificacion/README.md): Regresión logística, SVM, kNN, árboles, Random Forest, Gradient Boosting.
- [04-aprendizaje-no-supervisado](04-aprendizaje-no-supervisado/README.md): Clustering y PCA.
- [05-aprendizaje-por-refuerzo](05-aprendizaje-por-refuerzo/README.md): Q-Learning, DQN, Policy Gradient, Actor-Critic.
- [06-checkpoint-modelos-clasicos](06-checkpoint-modelos-clasicos/README.md): Proyectos integradores.

## Cómo avanzar

Practica con datasets clásicos, compara algoritmos y evalúa correctamente con validación.
