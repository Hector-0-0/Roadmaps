# Recursos - ¿Qué es un Machine Learning Engineer?

## Documentación oficial
- **scikit-learn Documentation**: [scikit-learn.org/stable/](https://scikit-learn.org/stable/) - Documentación oficial para flujos de ML con scikit-learn.
- **NumPy Documentation**: [numpy.org/doc/](https://numpy.org/doc/) - Referencia oficial para arreglos y operaciones numéricas.
- **Python Documentation**: [docs.python.org/3/](https://docs.python.org/3/) - Documentación oficial del lenguaje Python.

## Lectura o curso reconocido
- **Mathematics for Machine Learning**: [mml-book.github.io](https://mml-book.github.io/) - Fundamentos matemáticos para entender algoritmos de ML.
- **Dive into Deep Learning**: [d2l.ai](https://d2l.ai/) - Libro interactivo con ejemplos aplicados y código ejecutable.
- **Deep Learning Book**: [www.deeplearningbook.org](https://www.deeplearningbook.org/) - Referencia clásica sobre fundamentos de aprendizaje profundo.
