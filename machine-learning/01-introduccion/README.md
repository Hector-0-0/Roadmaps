# Introducción

## Objetivo

Esta etapa tiene como objetivo presentar el rol de Machine Learning Engineer, sus diferencias con otros perfiles, las habilidades necesarias y las responsabilidades que implica llevar modelos de Machine Learning a problemas reales.

## Mapa de temas

- [01-que-es-un-ml-engineer](01-que-es-un-ml-engineer/README.md): Definición del rol, tareas principales y contexto de trabajo.
- [02-ml-engineer-vs-ai-engineer](02-ml-engineer-vs-ai-engineer/README.md): Comparación entre perfiles, solapamiento y cuándo elegir cada camino.
- [03-habilidades-y-responsabilidades](03-habilidades-y-responsabilidades/README.md): Habilidades técnicas y blandas, responsabilidades diarias y enfoque práctico.

## Cómo avanzar

Estudia cada tema en orden, ejecuta los ejemplos con Python, resuelve las prácticas y revisa los recursos oficiales. Usa el archivo `PROGRESO.md` para marcar tu avance.
