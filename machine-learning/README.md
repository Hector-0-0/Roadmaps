# Machine Learning

## Objetivo

Formar un Ingeniero de Machine Learning capaz de comprender fundamentos matemáticos, preparar y analizar datos, aplicar algoritmos de Machine Learning clásico y Deep Learning, evaluar modelos con rigor y llevar proyectos de punta a punta desde los datos hasta un modelo evaluado.

## Público objetivo

Personas con bases de programación que desean especializarse en Machine Learning, con enfoque práctico y teórico equilibrado para aplicar modelos en problemas reales.

## Atribución

Este roadmap está basado en el roadmap correspondiente de [roadmap.sh](https://roadmap.sh) y el contenido educativo es propio.

## Prerrequisitos

- Fundamentos de programación y Python roadmap. Se recomienda haber completado o dominar sintaxis básica, estructuras de datos, funciones y archivos en Python antes de iniciar este roadmap.

## Nota sobre checkpoints

Los checkpoints de este roadmap no vienen en el original de roadmap.sh. Son un añadido para practicar con proyectos integradores. Cada checkpoint contiene 3 proyectos de dificultad creciente con objetivo, conocimientos que consolida, descripción, requisitos funcionales, habilidades que practica, criterios de aceptación y mejoras opcionales.

## Entorno

Para ejecutar las prácticas de este roadmap se recomienda usar un entorno aislado:

```bash
python -m venv .venv
source .venv/bin/activate  # En Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Consulta `requirements.txt` para ver las dependencias utilizadas en las prácticas.

## Cómo estudiar

1. Lee la teoría del tema en orden, ejecutando los ejemplos en Python.
2. Resuelve todos los ejercicios de `practica.md` siguiendo el formato indicado.
3. Revisa `recursos.md` con fuentes oficiales.
4. Completa los checkpoints al terminar cada bloque temático.
5. Usa `PROGRESO.md` para llevar seguimiento.
