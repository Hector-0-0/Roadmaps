# Evaluación de modelos y scikit-learn

## Objetivo

Aprender métricas correctas, validación, regularización y el flujo completo con scikit-learn para entrenar modelos confiables.

## Mapa de temas

- [01-metricas-de-evaluacion](01-metricas-de-evaluacion/README.md): Accuracy, precision, recall, F1, ROC-AUC, log loss, matriz de confusión.
- [02-train-test-y-validacion-cruzada](02-train-test-y-validacion-cruzada/README.md): Split, K-Fold, LOOCV.
- [03-regularizacion](03-regularizacion/README.md): Lasso, Ridge, ElasticNet.
- [04-scikit-learn](04-scikit-learn/README.md): Flujo completo con pipelines.
- [05-checkpoint-evaluacion-y-scikit-learn](05-checkpoint-evaluacion-y-scikit-learn/README.md): Proyecto integrador.

## Cómo avanzar

Enfócate en elegir métricas correctas según el problema y usar validación rigurosa.
