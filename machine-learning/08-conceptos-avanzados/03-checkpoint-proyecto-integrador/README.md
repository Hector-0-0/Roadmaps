# Checkpoint - Proyecto integrador

## Objetivo

Desarrollar un proyecto completo de Machine Learning de punta a punta, integrando todos los conocimientos adquiridos a lo largo del roadmap.

## Conocimientos que consolida

- Fundamentos matemáticos y programación en Python
- Preparación y limpieza de datos
- Modelado con algoritmos clásicos y técnicas apropiadas
- Evaluación rigurosa con métricas correctas
- Documentación y pensamiento crítico

## Proyectos

### Proyecto 1: Análisis exploratorio completo (Dificultad: Básico)

**Descripción:** Realizar EDA completo de un dataset público usando todas las técnicas de preparación aprendidas.

**Requisitos funcionales:**
- Cargar dataset público con código
- Limpieza y análisis estadístico
- Visualizaciones con Matplotlib/Seaborn
- Hallazgos documentados numéricamente

**Habilidades que practica:** EDA, pandas, visualización

**Criterios de aceptación:**
- EDA completo con hallazgos
- Gráficas con etiquetas
- Código reproducible

**Mejoras opcionales:**
- Comparar múltiples variables
- Detectar outliers

### Proyecto 2: Modelado con validación rigurosa (Dificultad: Intermedio)

**Descripción:** Entrenar y evaluar modelos con validación cruzada, evitando fuga de datos usando pipelines.

**Requisitos funcionales:**
- Preprocesamiento correcto
- Pipeline sin fuga de datos
- Validación cruzada
- Comparación de modelos
- Métricas apropiadas

**Habilidades que practica:** Modelado, validación, pipelines

**Criterios de aceptación:**
- Sin fuga de datos
- Validación cruzada aplicada
- Métricas numéricas reportadas
- Selección justificada

**Mejoras opcionales:**
- Ajuste de hiperparámetros
- Feature engineering

### Proyecto 3: Proyecto integrador final (Dificultad: Desafío)

**Descripción:** Proyecto end to end documentado con problema de negocio, datos, modelo, evaluación y conclusiones.

**Requisitos funcionales:**
- Problema claramente definido
- Pipeline completo reproducible
- Evaluación en test set
- Interpretación de resultados
- Documentación completa
- Código limpio

**Habilidades que practica:** Integración completa, documentación, pensamiento crítico

**Criterios de aceptación:**
- Proyecto reproducible
- Métricas en test reportadas
- Conclusiones basadas en evidencia
- Código ejecutable
- Limitaciones y mejoras documentadas

**Mejoras opcionales:**
- Consideraciones éticas
- Propuesta de despliegue
- Análisis de costo-beneficio
