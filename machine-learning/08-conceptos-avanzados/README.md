# Conceptos avanzados

## Objetivo

Explorar PLN, IA explicable y realizar un proyecto integrador de Machine Learning de punta a punta.

## Mapa de temas

- [01-procesamiento-de-lenguaje-natural](01-procesamiento-de-lenguaje-natural/README.md): Tokenización, stemming, lemmatización, embeddings, atención.
- [02-ia-explicable](02-ia-explicable/README.md): Interpretabilidad y explicabilidad de modelos.
- [03-checkpoint-proyecto-integrador](03-checkpoint-proyecto-integrador/README.md): Proyecto ML completo desde datos hasta modelo evaluado.

## Cómo avanzar

Integra todos los conocimientos adquiridos en un proyecto realista y bien documentado.
