# Práctica - Librerías de Deep Learning

## Nivel básico

1. **Comparación de frameworks**
   Enunciado: Compara TensorFlow/Keras y PyTorch en al menos 5 aspectos con tabla detallada.
   Pista: Incluye sintaxis, curva de aprendizaje, debugging, despliegue y ecosistema.
   Criterio verificable: Tabla con 5 aspectos y diferencias correctas para ambos frameworks.

2. **Concepto de tensor**
   Enunciado: Explica qué es un tensor y relación con arrays de NumPy usando ejemplos.
   Pista: Menciona dimensiones, tipos de datos y operaciones básicas.
   Criterio verificable: Explicación con ejemplos numéricos claros.

3. **Verificación de entorno**
   Enunciado: Escribe código para verificar disponibilidad de bibliotecas con try/except.
   Pista: Intenta importar tensorflow, torch y reporta estado.
   Criterio verificable: Código ejecutable que reporta disponibilidad correctamente.

## Nivel intermedio

4. **Flujo de entrenamiento**
   Enunciado: Describe flujo típico de entrenamiento en Deep Learning paso a paso.
   Pista: Incluye datos, modelo, función de pérdida, optimizador, epochs, validación.
   Criterio verificable: Flujo con 7 pasos detallados y correctos.

5. **Selección de framework**
   Enunciado: Para 3 casos de uso elige framework justificando con criterios objetivos.
   Pista: Casos: investigación, producción móvil, prototipado rápido.
   Criterio verificable: Elección justificada con al menos 3 criterios por caso.

6. **Recursos oficiales**
   Enunciado: Lista 3 recursos oficiales por framework con descripción de uso.
   Pista: Usa documentación oficial verificable.
   Criterio verificable: 6 recursos con descripciones correctas.

## Nivel desafío

7. **Análisis comparativo**
   Enunciado: Realiza análisis comparativo completo para un proyecto real propuesto.
   Pista: Incluye curva aprendizaje, despliegue, comunidad, mantenimiento.
   Criterio verificable: Análisis con criterios ponderados y conclusión razonada.

8. **Plan de aprendizaje práctico**
   Enunciado: Crea plan de 4 semanas para aprender uno de los frameworks con ejercicios concretos.
   Pista: Secuencial con objetivos medibles por semana.
   Criterio verificable: Plan con objetivos, recursos, ejercicios y criterios de logro.
