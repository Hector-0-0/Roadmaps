# Deep Learning

## Objetivo

Comprender redes neuronales, arquitecturas modernas (CNN, RNN, Transformers), autoencoders, GANs y su aplicación práctica.

## Mapa de temas

- [01-fundamentos-de-redes-neuronales](01-fundamentos-de-redes-neuronales/README.md): Perceptrón, MLP, activación, pérdida, backpropagation.
- [02-librerias-de-deep-learning](02-librerias-de-deep-learning/README.md): TensorFlow/Keras y PyTorch.
- [03-redes-convolucionales](03-redes-convolucionales/README.md): CNN, convolución, pooling, aplicaciones.
- [04-redes-recurrentes](04-redes-recurrentes/README.md): RNN, GRU, LSTM.
- [05-mecanismos-de-atencion](05-mecanismos-de-atencion/README.md): Atención y fundamentos.
- [06-autoencoders](06-autoencoders/README.md): Autoencoders y aplicaciones.
- [07-transformers](07-transformers/README.md): Self-attention, transformers.
- [08-redes-generativas-adversarias](08-redes-generativas-adversarias/README.md): GANs.
- [09-checkpoint-deep-learning](09-checkpoint-deep-learning/README.md): Proyecto integrador.

## Cómo avanzar

Practica con ejemplos claros, entiende conceptos matemáticos y ejecuta código con las librerías.
