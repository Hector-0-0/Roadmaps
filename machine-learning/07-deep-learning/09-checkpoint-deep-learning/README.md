# Checkpoint - Deep Learning

## Objetivo

Consolidar fundamentos de redes neuronales, arquitecturas y aplicación práctica con librerías de Deep Learning.

## Conocimientos que consolida

- Fundamentos de redes neuronales
- CNNs, RNNs, atención, transformers
- Autoencoders y GANs
- Uso de frameworks

## Proyectos

### Proyecto 1: MLP con dataset clásico (Dificultad: Básico)
**Descripción:** Implementar MLP simple para clasificación con MNIST o Iris.

**Requisitos funcionales:**
- Carga de datos
- Arquitectura MLP
- Entrenamiento y evaluación
- Métricas correctas

**Habilidades que practica:** Redes neuronales básicas

**Criterios de aceptación:**
- Modelo entrena correctamente
- Accuracy reportado
- Código reproducible

**Mejoras opcionales:**
- Regularización
- Early stopping

### Proyecto 2: CNN para imágenes (Dificultad: Intermedio)
**Descripción:** Clasificación con CNN usando dataset de imágenes.

**Requisitos funcionales:**
- Preprocesamiento de imágenes
- Arquitectura CNN
- Data augmentation básico
- Evaluación

**Habilidades que practica:** CNNs

**Criterios de aceptación:**
- Arquitectura correcta
- Entrenamiento estable
- Métricas reportadas

**Mejoras opcionales:**
- Transfer learning
- Visualización de filtros

### Proyecto 3: Proyecto integrador DL (Dificultad: Desafío)
**Descripción:** Proyecto completo con arquitectura moderna y evaluación rigurosa.

**Requisitos funcionales:**
- Problema definido
- Arquitectura justificada
- Entrenamiento con validación
- Evaluación completa
- Documentación

**Habilidades que practica:** Integración DL

**Criterios de aceptación:**
- Resultados reproducibles
- Métricas en test
- Análisis crítico
- Código documentado

**Mejoras opcionales:**
- Comparación con baseline
- Análisis de errores
