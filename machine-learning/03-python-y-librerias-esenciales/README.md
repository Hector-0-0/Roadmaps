# Python y librerías esenciales

## Objetivo

Dominar Python aplicado a Machine Learning y las librerías fundamentales para manipulación, análisis y visualización de datos: NumPy, pandas, Matplotlib y Seaborn.

## Mapa de temas

- [01-python-para-ml](01-python-para-ml/README.md): Sintaxis, tipos, estructuras de datos, funciones, bucles, excepciones, POO aplicado a ML.
- [02-numpy](02-numpy/README.md): Arreglos, indexado, broadcasting, operaciones vectorizadas y álgebra numérica.
- [03-pandas](03-pandas/README.md): Series, DataFrames, lectura/escritura, limpieza básica y agregaciones.
- [04-matplotlib](04-matplotlib/README.md): Gráficas básicas, personalización, subplots y visualización para análisis.
- [05-seaborn](05-seaborn/README.md): Gráficas estadísticas, distribuciones, correlaciones y visualización avanzada.
- [06-checkpoint-python-para-datos](06-checkpoint-python-para-datos/README.md): Proyectos integradores con las librerías aprendidas.

## Cómo avanzar

Practica con código ejecutable usando datos clásicos, resuelve las prácticas y verifica con `python3 scripts/verificar.py`.
